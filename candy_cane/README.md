# What If You Dropped a Candy Cane on Every World? (pixel short)

1080x1920, 60 fps, 38 s seamless loop, no voice.

One world at a time, full screen; the camera follows the cane as it falls from one world onto the next, and fades between worlds in the chorus. Each candy cane bounces with its world's real gravity, and every landing
is a beat: Earth = kick, Moon = bass (slow, floaty), Mars = clap, Jupiter = sleigh bells
("if Jupiter had a floor" - it has no solid ground). A string of Christmas lights plays the
Jingle Bells chorus (public domain), one bulb per note.

```
python3 audio.py audio.wav
python3 video.py candy_cane_every_world.mp4 audio.wav
```
